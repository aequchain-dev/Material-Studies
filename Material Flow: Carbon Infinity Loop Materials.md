## §VI — THE ATMOSPHERIC FAMILY'S GRID-DEPENDENCE, EXTENDED `[MODELLED]`

`graphene_laser` joins `cil_diamond` in the F2 pattern — and goes further:

Sign-flip threshold: 3.667 × 0.5 ÷ 1425 = **~4.6 g/kWh — below even best-case PV lifecycle intensity (18 g/kWh)**. Per-kg, laser graphene is carbon-positive on *any* real grid; its climate value is **waste-valorization + displacement** (diamond rejects → electronics feedstock), the same facility-level honesty F2 established for diamond. The certificate's "+50 t graphene storage" is a product-in-use claim, not per-kg sequestration.

## §VII — THE GLAZING→HTC→STAND LOOP (thanceln lens) `[MODELLED]`

The Transparent Wood line's residues close into the phyto-sterile agriculture that grows its own feedstock — quantified per 100 kt/yr panel line:

```
SRWC stands → TW line (100 kt/yr panels)
      ▲            │ residues 10–15 kt/yr [LITERATURE 10–15% of wood input]
      │            ▼
      │      htc_system (mass balance [SPEC])
      │  hydrochar 3.0–4.5 kt/yr → soil program 750–2,250 ha (2–4 t/ha maintenance)
      │  bioliquor 4.5–6.75 kt/yr = 4.5–6.75 ML Defense Nectar
      │      → foliar program 7,200–32,400 ha (1:50 dilution, 400–600 L/ha, 7–14 d cycle)
      │  carbon: ~3.75 kt hydrochar × 2.0 = ~7,500 t CO₂e/yr stored [SPEC certificate]
      └── +32% yield, +0.8% SOM/yr → more feedstock, better panels
```

**Discovery:** the foliar program covers *more hectares than the stands feeding the line* — the glazing line regenerates its own feedstock **with a fertility surplus that spills into the broader agriculture**. Combined with F18 (1 t TW co-feeds 0.45–0.63 t DLGC), the glazing program is now quantified as a two-loop keystone: resin loop to the flagship, fertility loop to the fields.
