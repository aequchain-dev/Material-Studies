## THE ONE DOCTRINE (uniform across all eight)

**The Four-Rung Materials Ladder** — applied without exception in every category:
1. **SUBSTITUTE** — eliminate demand for the critical/unsustainable material entirely
2. **REDESIGN** — change the machine so the substitute suffices (axial-flux for ferrite; coreless for Al windings; no-NPU for fab materials)
3. **CLOSE-LOOP RECYCLE** — the retained material flows through one industrial metabolism (E4 → E1 → fabricate → product → E4)
4. **TRACK EVERY GRAM** — NFC material passports, isotope verification, blockchain chain-of-custody

**Cross-cutting theses (proved in every study):**
- **Elements do not degrade** — dispersion is an engineering problem; "depletion" means dispersal, not destruction.
- **Waste is negative-cost feedstock** — the program is *paid to receive* its own inputs (demolition steel, fly ash, plastic, tires).
- **Honesty is a spec** — physics floors published (285 kWh/kg), deficits printed (betavoltaic 6.5 h), fallbacks specified (SrFe Y40H), predecessors falsified (Osmiroid, AVIS-CIL).
- **Three-tier graduation** — T1 existing sustainable → T2 advanced → **T3 diamond-sourced** (CIL as apex supplier to every product).
- **Status-tagging** — `[BLUEPRINT]` `[SPEC]` `[SOP]` `[LITERATURE]` `[ASPIRATIONAL]` `[UNVALIDATED]` on every claim.
